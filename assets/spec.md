重庆行业卡质检复核标注规范

# 目的

重庆行业卡主要用于拨打银行贷款营销、贷款催收、零售推销、房产中介等电话；为确保行业卡合法合规使用，需根据通话录音转写的ASR文本，识别该通话是否高风险涉诈；本规范旨在明确重庆反诈语音质检规则的复核规范要求，以便对基于AI模型的通话质检结果进行人工二次确认，确保通话符合业务安全要求。

# 复核规范

正常/违规场景判断 + 风险等级判断 + 判断说明

## 2.1正常场景

正常合规场景直接判断正常提交即可

## 2.2违规场景

1.场景优先级：涉诈类别 ＞ 违规业务大类（如贷款相关，法律服务） ＞ 引流第三方平台 ＞ 其他

**【案例佐证‑命中示例】**

通话内容：贷款推销，外呼人员说 “我这边稍后让客户经理加你的微信”。业务大类是【贷款相关】，行为属于【引流第三方平台】中由第三方添加用户微信，按规则贷款场景下第三方添加客户微信为低风险。标签选【贷款相关】，风险等级【低风险】。

2.风险等级优先级：高风险＞中风险＞低风险，就高不就低；多行为同时命中，取最高风险等级

**【案例佐证‑命中示例】**

通话内容：贷款推销，话术同时有 “不看征信可以办”（低风险）+“做黄金贷帮你周转”（高风险）。主标签贷款相关，最终风险等级判定高风险。

3.填写格式：【标签：具体违规行为简述】，禁止直接复制规则条文，必须结合 ASR 通话事实。

- 主标签选择：按照场景优先级匹配对应的业务大类；判定说明列明全部命中行为。
- 整体复核操作流程：

（1）通读 ASR 全文，识别通话全部业务行为；

（2）第一步优先判断：是否命中 4.2 中涉诈类型，涉诈全部为高风险；命中则直接选用对应涉诈标签；

（3）未命中涉诈：判断属于哪一类违规业务大类（4.1.1‑4.1.8）；

（4）识别全部风险行为，按就高不就低确定最终风险等级；

（5）选择主标签，填写判定说明；

（6）边界存疑通话，反馈并确认风险。

填写示例：

企业营销与招商服务：ai推广获客服务

贷款相关；拍拍贷平台贷款推销

证券投资类：引导参与抱团股票投资，签合同，涉诈

个体工商户年报补录收费：自称线上税务申报代办专员，引导通过服务号操作税务申报，缴纳补录费用，涉诈

# 原则

- 准确性：复核内容应准确反映语音沟通中的实际信息和意图。
- 一致性：对于相同的语音内容，应采用统一的复核方式，确保复核结果的一致性。
- 完整性：复核应涵盖语音沟通中的关键信息，包括但不限于问题类型、涉及主体、相关细节等。

# 安全策略

## 违规场景类别

- 针对每日AI质检结果异常通话，需根据通话内容判断是否存在违规场景；对确认违规通话，需进一步判断风险等级与复核说明总结；
- 说明：各类别中案例查阅【4.4典型话术举例和分析】

### 引流第三方平台

- 违规场景与风险等级说明

**合规**
- 1.外呼人员主动添加用户微信；
- 2.通话内只提及加微信，未明确主动添加方为哪一方，或没有要求对方添加、搜索、联系的动作；
- 说明：不区分场景，均为合规
- 例：外呼人员表述：我稍后加您微信（外呼方主动添加客户）

**低风险**
- 1.由第三方添加用户微信：贷款场景为低风险，标签归属【贷款相关】；
- 排除：除贷款场景，其他场景合规
- 例：外呼方告知客户：后续会有第三方业务人员来添加你的微信；

**高风险**
- （其他违规大类场景通用）
- 非个人微信类：如QQ、YY、微信群、福利群、qq群；下载APP、点击链接、扫二维码、关注公众号/服务号。
- 2.个人微信：引导用户主动添加微信（包括让用户添加外呼人员本机号码微信，以及第三方微信）
- 排除：业务官方正规 APP/公众号；
- 例1：引导下载会议软件开启屏幕共享指导操作，点击链接安装指定投资/贷款APP；
- 例2：明确要求客户主动去搜索号码添加外呼方 / 第三方微信

**升级涉诈**
- 1.贷款场景引导用户主动添加第三方微信，直接升级归类到【4.2.7 引导贷款用户添加第三方微信】涉诈
- 例：这边需要您添加一下我们经理企业微信沟通，我这边给您说一下号码

### 贷款相关

- 违规场景与风险等级说明

**合规**
- 1.合规渠道：银行、银行消费金融、融三六零平台贷款；
- 2.助贷包装合规：个人贷款包装为经营性贷款、大额分期卡团办形式，正常银行渠道贷款，无需用户找第三方介入，收取合理助贷服务费/担保费/资料包装费，助贷费用不超过下款金额10%（10个点以内），下款后收取，可判定正常合规；排除：若同时引导加微信/对接第三方/人工审核/下款经理/放款经理等，不得据此判合规，应优先按【引导贷款用户添加第三方微信·涉诈】判定；
- 说明：如明确为持牌银行/持牌消费金融/官方APP等正规渠道，且仅客观告知贷款利息、风险提示，不存在下列违规话术，不属于违规。排除：若主体身份模糊（如自称『贷款客服/放款经理/客户经理』等非持牌渠道，或无法核实为官方持牌机构），即便仅告知利息/额度，不得据此判合规，应进一步按涉诈/违规口径判定。

**低风险**
- 1.过分承诺：包过、包批、100%下款、内部渠道、零利息，以及『填多少批多少』『批多少是多少』等承诺性变体；
- 2.提前收取费用：即下款前收取，定金、诚意金、保证金、解冻金等前置费用；
- 3.网贷、小贷平台：度小满、安逸花、拍拍贷、分期乐、理想花、花呗、好分期、还呗、众安贷、信用飞、三六零借条、京东金融、闪小融、云闪付、有钱花、宜享花、优客花、\*\*钱包（微信钱包、小花钱包、微钱包等）、微信或支付宝\*\*小程序/服务号等；
- 4.其他非合规渠道：私人借款（一般为高息借款）；保险贷（保险形式放款，即钱先打到保险公司，由保险公司放款给用户，用户每月以还保单形式还款）（典型案例7）等；
- 5.不看征信：不看征信、不上征信、不查征信、规避征信系统、只看流水/收入、黑户可办、不看查询/负债/逾期/大数据；含『免审/免审核/零审核/免审备用金/免审核额度』等变体——正规持牌贷款必有审核，凡宣称『免审』即属违规信号，即便话术同时出现『备用金/额度』等词也不得套用合规口径；
- 说明：网贷、小贷平台如通话中有明确具体平台，需标注对应平台

**中风险**
- 1.诱导违规提取公积金；
- 2.承诺修复征信；
- 3.网贷平台客服以清除数据协助平台下款名义收取高额服务费（典型案例5）；
- 排除：仅推销公积金贷 / 公积金备用金，或贷款资质核验仅查询公积金缴存信息，未提及提取公积金余额，属于合规；判定核心区分：是否引导将公积金余额提取出来，单纯以公积金作为贷款授信资质不属于违规提取公积金。但若同时出现『免审/免审核/不看征信/不看查询』等违规信号，或引导关注公众号/加微信对接第三方，不得据此判合规，应优先按违规/涉诈口径判定。

**高风险**
- 1.高风险渠道：境外网贷、高炮贷款、境外高炮、不用还的贷款渠道（典型案例8）、高息贷款（持牌机构综合年化不可超 24%，民间借贷不可超 LPR4 倍司法保护上限。如：私人短期资金日息千分之五/十万额度日息六百，年化远超LPR4 倍）；
- 2.黄金贷——黄金分期变相借贷套路(典型案例9)；
- 3.债务优化：本质为提供债务的相关服务，如
- （1）提供债务优化服务，垫资或提供非合规资金渠道（如私人借款）结清高利息平台债务/逾期（垫资过桥），再办理低息贷款；
- （2）提供债务减免服务/专业处理短期高息债务/债务托管服务，协商债务本金或利息减免，甚至承诺债务不用还；
- （3）以其他名义，如法律咨询名义诱导做贷款替换；
- 4.砍头息贷款：服务费/担保费/资料费/包装费等助贷费用，超过下款金额10%（10个点以上），判定为砍头息，如贷款1w到手8k；
- 5.引导用户平台操作提现：以提额降息活动/关闭会员等为由引导用户进入小程序/服务号/公众号/app操作提现，偏套路贷，按高风险。（通话中常见平台：众安贷，小花钱包，信用飞，分期乐，还呗，三六零借条等）（典型案例6）
- 排除：
 （1）债务优化，排除：正常推销贷款场景，只是以债务优化为推广话术，例如正常推销合规渠道（如银行）低息贷款，仅作为推广话术称可用于债务优化/置换，为合规;
  (2) 引导用户平台操作提现,排除：合规平台如银行、融三六零官方app；

**升级涉诈**
- 贷款要求支付宝芝麻信用分：
- （1）如果没有明确是银行渠道，通话中要求提供支付宝芝麻信用分截图或者询问支付宝芝麻信用分情况，直接升级归类到【4.2.2 手机租赁套路贷诈骗】涉诈；
- Eg：手机租赁套路贷诈骗：贷款推销，要求提供芝麻信用分截图，疑似套路贷
- （2）如涉及引导对接第三方/添加第三方微信，直接升级归类到【4.2.7 引导贷款用户添加第三方微信】涉诈。
- 排除：如果提及支付宝芝麻信用分，但明确为银行渠道，无其他违规场景，为合规；

### 法律服务

- 违规场景与风险等级说明

**合规**
- 常规法律咨询，未涉及提前收费及以下违规场景，不命中；

**低风险**
- 1.常规法律机构以维权服务名义要求提前收费，如主张帮用户要回欠款、提供离婚诉讼服务、劳务纠纷等，需补缴手续费/保证金、验证资金流水要求多次转账、充值解冻账户、维权机构要求支付调档费等；（如案例1）
- 2.帮追回股票平台服务费，无论是否提及收费（如案例2）；
- 3.帮购买保险用户退回保险费，无论是否提及收费（如案例3）；

**高风险**
- 自称维权机构帮退律所费用，成功后收取服务费（如案例4）：即用户向网上律所缴纳费用后，对方未立案办事，用户自行投诉、沟通均无法退费。外呼方表明自身做维权退费业务，宣称可以退回律所费用，前期不收费用，退款到账后收取分成。

### 企业营销与招商服务

- （1）违规场景与风险等级说明

**合规**
- 1.品牌招商加盟：棋牌/零食店加盟、邀请阿里国际电商开店
- 2.淘宝闪购联盟功能开启

**低风险**
- 1.Ai/小红书等平台推广获客服务：收费将公司产品和服务等推广至各个平台，提升曝光度；
- 2.企业服务营销提前收费：会展营销、培训机构/学校招生、课程培训、考证服务、申报代办等，如需提前收费，按低风险，否则合规；
- 3.虚假承诺：教培、考证类承诺保过/包拿证。排除：教培、考证属于行业常规预收费模式，正常预收服务费不触发本条低风险标签，按正常业务判定；但如存在大额长周期预收、个人账户收款、培训贷捆绑、承诺保过/包拿证等违规情形，不适用本排除规则，需单独识别并判定对应风险标签。

**中风险**
- 1.企业违规涉税筹划、虚开成本票服务：虚开发票中介，注册第三方个体户核定征收买票冲成本，收取服务费，涉及违规涉税筹划、诱导虚开发票行为。（典型案例2）
- 2.企业重点人群补贴申报服务：第三方为企业提供重点人群补贴申报服务，到账后收取服务费；（如典型案例3）

**高风险**
- 1.大额长周期预收：大额长周期预收判定标准：面向中小学生 K12 培训，一次性收费时间跨度超过 3 个月或 60 课时，或金额超过 5000 元，即属于大额长周期预收；成人考证培训无全国统一强制限额，结合通话内容综合评估周期与金额。
- 2.培训贷捆绑：机构引导学员办理贷款 / 分期用于支付培训费，贷款资金直接给到培训机构，学员分期偿还贷款；话术常见 0 首付、先上课后交钱、学费分期。
- 3.个人账户收款：引导用户将培训费、服务费、教培费、课程费打到个人账户。

### 商品推销

- 违规场景与风险等级说明

**合规**
- 1.运营商相关业务办理如宽带、携号转网业务推销、校园网前置营销；为合规
- 2.外卖商家刷单：外卖商家要求用户下单后添加微信退款（典型案例2）；为合规

**低风险**
- 1.赠送pos机（即刷卡机）、或给pos机老用户赠送商品，涉及刷流水要求（典型案例1）：
- （1）赠送pos机涉及几百上千刷够流水后才能提现为低风险；
- （2）衍生场景—POS 机老客户回馈为由，免费赠送商品（如：电磁炉、运动手表），向用户确认收货地址，要求出示 POS 机、身份证、信用卡签收；如涉及更换机器并要求几百上千刷够流水后才能提现同为低风险；
- 说明：免费赠送pos机及为pos机老用户赠送商品，未涉及收费，或只收取正常运费，为合规；

**中风险**
- 保健品推销：免费领引流—>加微信后开始洗脑、推销高价保健品—>可能搞货到付款、到付运费、会员费、套餐费—>反复骚扰、连环下单，掏空老人积蓄；（典型案例3）
- 2.其他商品推销/赠送要求支付高额到付费用：免费赠送商品名义，实际要求支付高额到付费用。
- （如自称酒厂以免费赠送汾酒为名，实际要求用户支付99元到付费用）（典型案例4）；

### 商业地产

- （1）违规场景与风险等级说明

**合规**
- 1.商铺包租提前收取推广费：商铺转让中介要求签订合同，支付推广费,已确认为合规业务；
- 2.常规房产服务场景：（1）房产买卖场景（如交易看房预约、房产信息沟通、房产交易后续事宜、售卖房产沟通、置换房产咨询、房产信息登记等）；（2）房产租赁场景（如房产信息沟通、房产租赁需求、房产中介出租服务介绍、租赁看房预约等）；

**低风险**
- 法拍房处理：用户欠债房子被拍卖，代处理法拍房问题；

**中风险**
- 代客运营租房装修收费：长期合作代运营租房，需先按指定风格委托为房子装修并收取装修费用；

### 违规催收

**合规**
- 对本人催收、客观告知逾期后果，协商还款，无威胁恐吓;

**低风险**
- 1.催三方：向欠款人的亲友、同事等非本人催收；
- 2.暴力催收：如威胁联系亲友、上门催收、报身份证/住址威胁等存在威胁施压行为（如典型案例1）；
- 3.律师身份催收：自称律所/律师事务所催收欠款，以诉讼、诉前调解等施压催收；

**高风险**
- 1.冒充公检法催收：冒充法院人员，司法调节站人员，诉讼中心人员等公检法人员，实际目的为催收；（如典型案例2）；
- 2.催收同时诱导逾期用户以贷养贷：平台催收人员向逾期客户实施催收，同时推销还借宝业务，诱导用户购买超市卡并还款解除逾期状态后，获取二次借款额度（常见平台：分期乐）（如典型案例3）；

### 其他

- （1）违规场景与风险等级说明

**高风险**
- 1.外呼人员骗取身份证号、完整家庭住址、银行卡、短信验证码等敏感隐私信息
- （涉及敏感隐私信息，需根据具体场景判断是否合理，如存在骗取个人信息风险，为高风险；）
- 2.不属于上述任何场景，但是存在异常风险行为，标记标签【其他】，判定说明完整描述实际行为。
- 排除：业务办理必要信息，客户自愿主动提供，业务流程合规，不属于违规。例如：贷款场景要求客户携带身份证、银行卡线下办理，符合常规业务流程，为正常合规。

## 涉诈场景类别

针对部分违规场景，需结合具体通话情境判断是否存在涉诈可疑风险，涉诈优先级最高，一旦命中，直接选对应标签,不再选用普通违规大类标签。（涉诈场景风险等级均为高风险）

- 说明：各类别中案例查阅【4.4典型话术举例和分析】

### 机票退、改签诈骗

(1) 诈骗套路说明
- 第一步：诈骗分子致电受害人谎称自己是某某航空公司客服（一般骗子手中有受害人机票具体信息），告知航班由于设备故障无法正常起飞，询问受害人是改签还是退票。
- 第二步：诈骗分子主动告知受害人为了表示歉意会下发300元理赔金，需要受害人操作申领。
- 第三步：诈骗分子会指导受害人操作支付宝账户，期间由于查询不到信息让受害人下载会议软件共享屏幕。
- 第四步：诈骗分子操控受害人手机进行转账等。

（2）判断方法
- 命中以下两个及以上核心特征即可判定为高风险涉诈：
- 身份冒充：自称航空公司、机场客服
- 事由铺垫：提及航班延误、故障、取消、停飞
- 利益诱导：提及退票补偿、改签理赔、发放赔偿金
- 风险动作：引导下载软件、开启屏幕共享、操作转账、点击陌生链接

**【排除情形（不命中）】**

- 真实航空公司客服，正规办理退改签，没有理赔诱饵、没有引导共享屏幕转账等风险行为，不属于涉诈。

### 手机租赁套路贷诈骗

（1）诈骗套路说明
- 第一步：诈骗分子找到有资金周转需求的用户，以支付宝租手机的方式，让用户在支付宝下手机租赁订单；
- 第二步：平台发货后，将手机转寄给诈骗分子，诈骗分子再将用户需要的周转资金发给用户，但用户需要后续支付手机的每月租赁费用；
- 第三步：租赁到期后，用户是需要退还手机的，如不退还，会产生逾期或者需要支付买断费用，但由于手机在诈骗分子手里，所以用户无法退还手机，因此用户需要承受高额的损失。

（2）判断方法
- 命中任意 1 条即可判定涉诈 ：
- 外呼话术直接/间接引导客户：租赁手机、电子产品，拿到设备之后进行变卖、回收、套现，从而获取周转现金；
- 外呼中介介绍业务：明确说明手机不用本人自用，租机目的就是拿钱，手机交由中介/合作商家处理回收；
- 催收通话场景：针对上述 “租机套现” 模式产生的债务，向当事人开展催收；
- 传授规避租机平台审核话术：教唆客户向平台谎称手机个人自用，实际用来套现拿钱。

**【排除情形（不命中）】**

- 客户租赁手机用于本人日常自用，不进行变卖、套现换现金，不属于本涉诈场景。

### 证券投资类

（1）诈骗套路说明
- 第一步：以官方福利群的名义（有些通话会提及投顾服务、投顾产品）引导添加服务号，并让置顶服务号，取消消息免打扰。
- 第二步：让用户托管账号给他们代理操作，收取会费或佣金形式进行合作。
- 第三步：引导用户投入资金，并以各种理由致使用户无法提现。

（2）判断方法
- 命中任意 1条特征，即可判定涉诈 ：
- 1.身份话术：自称证券公司、投顾机构、股票软件、私募机构等身份开展荐股、营销、回访；
- 2.荐股并夸大 / 虚假承诺收益：推荐具体个股/标的，并伴随 "拉涨停、\*个点以上拉升、内部消息、自有资金 / 主力资金 / 庄家做拉伸、稳赚、兜底、全额补亏、胜率\*%、综合收益\*%、翻倍收益" 等夸大或承诺性收益话术；
- 3.组建炒股群，引导添加第三方渠道：组建 "内部核心群、内部交流群、VIP 会员群、散装联盟、跟单群" 等，引导添加微信、钉钉、QQ、飞书、企业微信、公众号、助理等第三方渠道；
- 4.推销付费 / 分成 / 会员服务：推销荐股分成、投顾服务费、会员费、入会费、跟单费等，或以 "先观察、赚钱后分成、免费体验" 等话术诱导后续付费；
- 5.诱导追加资金 / 建仓 / 入金：诱导客户 "调仓、建仓、加仓位、凑仓位、腾资金、入金、投入几万、参与市值管理 / 合力建仓" 等，引导向股市投入或追加资金；
- 6.远程指挥买卖 / 代操盘：提供所谓 "精准买卖点"，电话 / 群内直接指挥客户买入卖出，或声称 "帮您操盘、带您操作、代操作"；

**【排除情形（不命中）】**

1.其他场景通话中如贷款场景，仅提及理财产品、股票知识，不承诺收益、不诱导建仓入金、不引导添加第三方渠道等上述行为，不判定涉诈；

2.客户单方面口述自己曾遭遇荐股被骗经历，外呼人员没有实施上述任何推荐、诱导动作，不判定涉诈。

### 网贷平台退息退费

（1）诈骗套路说明
- 以法律维权协助办理网贷平台退息退费为由，引导添加法务老师微信，退费后付款；实际加微信后有可能涉及骗取个人信息以及要求转账付费等风险；（典型案例1）
- 自称平台退费人员/维权机构工作人员，承诺帮退网贷平台担保费会员费。（典型案例2）

（2）判断方法
- 命中任意 1 条特征，即可判定涉诈：
- 1.过度虚假承诺：宣称 "高炮 / 网贷一分钱不用还"" 利息全部退回来 ""白得的钱"" 不上征信、无任何影响 ""高息债务可免除" 等明显违背常理的承诺；
- 2.教唆造假退费：引导 / 教唆客户向网贷平台、银行客服编造虚假理由（如 "我不知道会员费"" 没使用过 ""态度强势要求退"" 投诉到银监会 "）进行退费操作；
- 3.诱导向平台施压退款后再收费：怂恿客户以投诉、曝光等施压手段向网贷平台 / 银行施压索要退款。
- 4.冒充法务 / 债务处理 / 维权机构等专业身份，宣称可帮退息退费；
- 5.宣称可退回网贷 / 信用卡的会员费、担保费、权益费、超法定利率利息、违约金、年费等费用；

**【排除情形（不命中）】**

- 1.客户主动向网贷平台、银行官方客服咨询退费，官方正规流程处理，不判定涉诈；
- 2.仅客观告知合法退费维权途径，不承接代办、不诱导加私域微信、不索要隐私、不承诺收益，不判定涉诈；
- 3.客户单方面口述自己曾遭遇退息退费被骗经历，外呼人员未实施上述任何诱导、承诺、操作动作，不判定涉诈。

### 个体工商户年报补录收费

（1）诈骗套路说明
- 1.年报补录类
- 自称线上税务服务中心点/营业执照线上税务代办，引导添加企业微信，以个人工商户未按时进行年报申报为由，要求在小程序缴纳信息补录费用；实际年报申报完全免费，不存在信息补录费一说，只在管理办法中提及可能被政府罚款，网上也有很多该类诈骗案例。
- 2.环保登记（排污登记）类
- 自称环保登记办/环保服务中心/企业环保登记办/环保登记服务办等官方身份，谎称固定污染源排污登记表未申报、排污许可凭证过期失效、环保登记未提交，诱导添加企业微信或跳转公众号/第三方平台/小程序，以 "环保 / 排污登记、续登、建档" 为名收取费用，或索要身份证号、手机号等个人信息的诈骗行为。
（2）判断方法
- 命中任意 1 条特征，即判定为涉诈：
- 年报补录类（典型案例1）：
- 1.冒充官方身份：冒充官方/代办身份（市场监督管理局、工商局、税务局、营业执照服务中心、线上税务代办专员，或环保登记办、环保服务中心等）；
- 2.引导第三方渠道办理：引导客户添加 "服务大厅企业微信、联保专员、客服微信"，或点击 "自助服务平台、企业一站式服务平台、快办助手" 等第三方链接 / 小程序办理年报补录、解除异常、注销；
- 3.在线收取补录 / 异常 / 注销费用：以 "年报补录、解除经营异常、执照注销" 为由，要求客户在线支付补录费、处理费、注销费等费用；
- 4.谎称经营异常并施压：谎称营业执照 "经营异常、脱审、漏报、列入异常名单"，以罚款、影响法人征信、今后无法办执照等后果施压，诱导处理；
- 5.索要个人敏感信息：以年报、补录、注销业务为名引导客户填写身份证号、手机号、姓名、住址、银行卡等个人信息。
- 环保登记（排污登记）类（同类话术）（典型案例2）：
- 6.冒充环保官方身份：自称 "环保登记办、环保服务中心、企业环保登记办、环保登记服务办" 等官方 / 代办身份，办理固定污染源排污登记、排污许可凭证续登、环保登记备案业务；
- 7.谎称排污 / 环保登记未申报或过期：谎称客户 "固定污染源排污登记表未申报、排污许可凭证过期失效、环保登记未提交、两证不齐全"；
- 8.引导公众号 / 第三方平台操作：引导客户在微信搜索 "环服办 / 环护办" 等公众号，填写员工工号、企业查询、身份认证，或点击第三方申报平台操作；
- 9.收取登记建档费：以 "登记建档费、首次登记费、续登费、注销费" 为由，要求客户在线支付（常见约 400‑500 元），诱导扫码支付；
- 10.索要个人 / 企业信息：以排污登记/环保登记为由引导客户填写身份证号、手机号、姓名、企业名称、法人信息等。

**【排除情形（不命中）】**

- 市场监管、税务等真实官方机构通过官方渠道（政府网站、渝快办 / 愉快办等官方政务平台）免费提醒年报申报，不引导第三方渠道、不收费、不索要敏感信息，属于正常业务，不判定涉诈;
- 营业执照相关业务线下代办（申办、注销等）为正常业务，不判定涉诈；

### 贷款相关-ab贷

（1） 诈骗套路说明

借款人本人资质无法放款，中介编造风控理由，哄骗亲友第三方出面，以代收、过账、受托支付、担保、紧急联系人、背调等名义，实际让第三方承担全部借款债务。

（2）判断方法
- 命中任意 1 条特征，即判定为ab贷涉诈：
- 1.需要借款人找第三方账户代收贷款资金/到账后转第三方账户，收款后取现给贷款人；
- 2.受托支付、委托支付等方式，需找第三方做资金断流；
- 3.借口风控背调，以贷款人征信/账户存在问题，要求找亲友做紧急联系人/到场核实情况/接听电话/找工作稳定的亲友了解情况；
- 让第三方做担保、双签，来给资质不足的借款人放款；

**【排除情形（不命中）】**

亲友自愿顶名借款，无中介欺骗隐瞒（双方事前全部知情），不属于ab贷。

即：A 资质差，B 自愿同意以自己名义贷款，B 完全清楚自己是主借款人、要承担债务，不存在中介虚假承诺 “只是帮忙不负债”。

### 引导贷款用户添加第三方微信

- （1）诈骗套路说明
- 平台客服，以人工审核名义，核对用户信息后，引导用户主动添加第三方（下款经理/放款经理/客户经理/接待经理等身份）微信/企业微信；
- 目前存在此套路较多的网贷平台为安逸花、分期乐、还呗、中信消费金融、招联金融等；
- 有些通话可能未明确说到加微信，但提及对接经理（第三方），为同样套路（如典型案例2）。
- 部分话术为引导用户关注公众号后，通过公众号对接人工客服/放款经理，为相同套路（如典型案例3）
- （2）判断方法
- 本类诈骗为贷款场景下的组合判定：『贷款场景』成立时，若命中『引导添加/对接第三方』任一项（含『对接一下』『拉您进群』『我拉个对接的群』等非标准话术变体），即可判定为【引导贷款用户添加第三方微信诈骗】；仅当『引导添加/对接第三方』完全无任何引导或对接迹象时才不判本类型。
- 条件一：贷款场景识别（满足以下任一特征，即构成 "贷款场景"）
- 1.围绕贷款业务开展：通话内容围绕贷款、借款、资金周转、放款、下款、额度、还款期限等贷款事项展开；
- 2.自称贷款平台 / 人工审核：自称好分期、中信消费金融、安逸花、招联金融等知名平台人工客服或线上人工审核；
- 3.以征信问题诱导：谎称客户 "点击网贷多、查询次数多、征信花、综合评分不足" 被大数据拒贷，需 "转人工审核" 才能下款；
- 4.承诺低息高额快速放款：宣称 "月息三厘 / 四厘 / 六厘、额度\*万、当天 / 1‑2 小时 / 24 小时放款"，诱导办理。
- 条件二：引导添加 / 对接第三方识别（满足以下任一特征，即构成 "引导添加第三方"）
- 1.引导添加第三方微信：引导客户打开微信→添加朋友→企业微信联系人→搜索号码，添加 "经理 / 客户经理 / 放款经理 / 审核经理 / 接待经理" 等第三方的个人微信或企业微信；
- 2.引导对接第三方：引导客户对接第三方机构、客服、企业微信、拉入 "监督群 / 服务群" 等第三方渠道办理贷款、对接放款；
- 3.索要发送个人信息给第三方：要求客户添加后向第三方发送姓名、贷款金额、手机号、微信名等；
- 4.诱导向第三方隐瞒真实情况：叮嘱客户向第三方谎报 "无逾期、无黑户"，或按指定金额 / 话术申报；
- 5.外呼方以『我先加你微信 / 我用企业微信加你』名义主动加微信后，再称对接下款/放款/审核经理或转交他人办理——只要存在『加微信后对接第三方放款』的实质，同样判本类涉诈。

**【排除情形（不命中）】**

- 仅当外呼方为明确持牌银行/官方APP官方客服、主动加微信仅为办理本机构自身业务（无对接第三方、无人工审核转交）时才豁免为合规；非贷款场景引导主动添加仍按引流第三方平台高风险违规。

### 套路运诈骗

- （1）诈骗套路说明
- 招聘货运、客运司机，分仓库、非仓库两种拉货模式；提供多站点和固定路线，车子不收押金租金保证金，平台派单只需司机负责送货；
- 入职收取司机800元平台注册费/开卡费，承诺做满一个月退500；
- （2）判断方法
- 命中以下两个及以上核心特征即可判定为高风险涉诈:
- 高薪招聘货运/客运司机；
- 宣称仓库、多站点、多条固定派单路线；
- 入职阶段收取注册费、开卡费、会员费、信息费，承诺后期返还。

**【排除情形（不命中）】**

## 违规场景涉诈判断与补充

### 场景补充：

- 如发现通话中存在其他违规场景，可根据具体场景进行复核标注，对于新增类型违规场景，按以上同类型场景进行风险等级判定；如不属于上述类型违规/涉诈场景，可判定为其他。

### 违规场景涉诈判断：

- 如发现违规场景中部分类型疑似涉诈，可按如下流程做进一步判断。
- （1）通过多个同类型疑似涉诈的违规通话综合判断；
- （2）对通话中提到的相关平台（如公众号/服务号、小程序、app等）进一步核查，如涉及相关经营主体或IP地址，可通过企查查/爱企查等查看主体是否经营异常，如IP地址为境外通常大概率为涉诈；
- （3）通过互联网平台如小红书、抖音、ai工具等搜索是否有相关诈骗套路分享，如有，基本可判断为涉诈与大致套路类型。
