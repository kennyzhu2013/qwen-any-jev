## 4. 复核过程中确认的关键 spec 口径（供后续标注/模型校准）

1. **冒充公检法催收 ∈ 违规催收-高风险**（4.1.7），不属于 4.2 涉诈清单；律师/律所身份走诉讼催收 = 低风险；"人民法院调解平台特邀调解员/诉前调解站"（ASR 变体：数条站/苏条站/塑条站/速条上/塑料站等）话术即冒充法院人员。
2. **ab贷涉诈须实质特征**：第三方代收贷款资金/到账转第三方/资金断流/受托支付/双签（否定式"不双签"不触发）/顶名/找亲友担保到场接电话；"找人过账""第三方担保公司出具非恶意逾期证明"均算实质特征。
3. **引流口径**：外呼人员主动加用户微信 = 合规（不分场景）；第三方经理添加用户 = 贷款低风险；引导用户主动搜索添加个人微信 = 高风险；贷款场景 + 引导加第三方微信 = 升级 4.2.7 涉诈；"关注服务号→要下载链接→浏览器安装 APP" = 引流高风险。
4. **4.2.7 条件二含"诱导向资方隐瞒真实情况"**：叮嘱客户谎报资金来源、勿提中介、不接听审核电话等，即便加微动作由外呼方发起也判涉诈。
5. **债务置换**：中介明确结清/垫资过桥/减免 → 贷款高风险；仅银行渠道推广话术 → 排除合规；主体身份模糊（自称贷款客服/放款经理/稳岗中心/渠道部）→ 不得判合规。
6. **催收同时推销还借宝/超市卡解逾期再借** = 违规催收-高风险（4.1.7-2，常见平台分期乐；ASR 变体环借保/环解保/还借保）。
7. default_low 兜底标签不可作准：本轮 51 条 default_low 多数实为中介营销低风险信号成立（不看征信/流水贷/服务费点数），但需逐条读原文确认。
