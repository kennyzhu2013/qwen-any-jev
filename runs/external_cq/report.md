# 重庆行业卡外部正常集 · v2 冻结 probe 复评（2026-11-20）

## 1. 数据与口径

- 来源：`/nfsdisk3/dataset/industry_card/chongqing/trainning_summary/chongqing20261030-1102_normal_match_result.csv`
- 原始 8,284 条；按规范化转写去重 15 条、剔除与 v2 内容重合 1 条，保留 **8,268 条**（callid 全唯一）。
- 口径：旧 `label=正常` 且 `CQ_Agent_res=正常`；来源日期 2026-10-30 / 11-01 / 11-02；与 `eval_v2/goldens.jsonl` 的 callid 和内容重合均为 0。
- 特征：`eval/features.py --task v2`，Qwen3.5-4B 最后一 token，层 8/16/24/32；冻结头 `runs/v2/probe/probe_head.npz`（layer 24 / L2 0.1 / balanced）。
- 阈值：直接读取 `runs/v2/gate_results.json` 的 argmax 与三个 dev 冻结操作点，未在新数据上重新选点。
- 局限：这是「旧标 + agent 都判正常」的条件样本，agent 对 4.2 有漏报（重合核对 recall 0.73），因此实测 FPR 是偏保守的上界；且 10-30..11-02 不是严格未来窗口。
- 负类可靠性（重合 4,670 条核对）：agent 判「正常」的行 v2 4.2 涉诈率 0.8%（6/731），agent 判「违规」的行只有 0.1%（4/3,829）；不可靠的是 agent 判「涉诈」（precision 0.245）。因此 agent 正常/违规可以作为外部负类，agent 涉诈必须复核。
- 注意：agent 判「正常」不等于 v2「合规」；重合样本中 agent 正常的行仍有 99.7% 被 v2 判为 4.1 违规。本文的 FPR 指「4.2 涉诈误报率」，这些 4.1 违规按 4.2 任务的负类处理。

## 3. 结论

- 在这批新正常流量上，冻结阈值基本按 dev 目标迁移：FPR5 实测 4.1%（最保守 4.5%），接近 dev 的 5%；argmax 仅 1.4%。
- 因此 v2 报告里 gate 主门禁负类 15.2% / `human_cq_normal` 14.9% 的高误报，主要不是普遍的时间漂移，而是那两个负类集合的构成（167/230 为仅 4.1 违规；cq_normal 为 8 月批次）。部署前仍应按目标流量校准，但这批数据支持 `@FPR5` 在正常流量上可用。
- 召回尚不能在这批数据上评估：需要先复核 220 条 agent 涉诈候选（`1030_normal_unmatch` 134 + `1113` 86），确认 4.2 正例后再做时间外推。

## 4. 复核队列

已生成 `runs/external_cq/review_queue_external.xlsx`（机读副本 `review_queue_external.csv`）：

| 队列 | 条数 | 用途 |
|---|---:|---|
| agent 涉诈 | 207（1030 正常冲突 134 + 1103-1113 73） | 14 条 ab贷 已确认；其余 193 条抽样/待定 |
| 正常冲突（仅 4.1） | 335 | 硬负例候选，不是正例 |
| 旧涉诈、agent 正常 | 406（随机抽 100） | 判断旧标噪声还是 agent 漏报 |

**当前标签策略**（详见 `labeling_policy.md`）：

- 1103-1113 的 14 条 ab贷 直接确认为正例（`confirmed_positive.csv`；其中 1 条 conf=0.72 已标记建议快速复核）。
- 其余 193 条按场景分层抽样 88 条（n≤10 全看，否则 20%、最少 10、最多 20），见 `review_sample.xlsx` / `review_sample.csv`。
- 抽样复核后，某场景精度点估计 ≥0.90 且 Wilson 下界 ≥0.70 时，该场景剩余行自动采纳；否则保持待定，不进入正例/负例。
- probe 不作为佐证：它是待评估模型，用它的判断挑正例会高估 recall。与 v2 人工正例的 SimHash 近重复匹配在 Hamming ≤4/≤12 均为 0 条，暂无可用的逐条佐证。

agent 涉诈的置信度分布：ab贷 18 条中 14 条 conf≥0.9；引导加微 89 条中仅 17 条 conf≥0.9。复核建议见工作簿「说明」页。

按历史精度粗估，207 条中真正 4.2 可能只有几十条（ab贷 18×0.75≈14；引导加微 89×0.017≈2；年报/验证码/手机租赁样本太少）。因此时间外推的 recall 置信区间会很宽，结论只能作方向性参考；要稳定估计 0.95 附近的 recall，仍需更多独立人工正例。

agent 涉诈候选（1030 的 134 条）的 probe 一致性：

| 场景 | n | probe 平均 P | P≥0.5 |
|---|---:|---:|---:|
| 引导加微 | 49 | 0.084 | 2 |
| 验证码/短信转发 | 23 | 0.071 | 1 |
| 年报补录 | 21 | **0.694** | **15** |
| 贷款相关 | 7 | 0.087 | 0 |
| ab贷 | 4 | 0.170 | 0 |
| 其他 | 7 | 0.126 | 0 |

年报补录是 agent 与 probe 一致的高风险类；引导加微/验证码 agent 置信度不低但 probe 基本不认，复核时应重点确认是否 agent 误报；ab贷 probe 可能漏，不能因 probe 低就判负。

## 5. 时间外推批次（11-04..11-13）描述性结果

`chongqing20261103-1113_match/unmatch` 原始 5,008 条；剔除 v2 重合 873 条、重复 callid 3 条、重复内容 166 条，保留 **3,966 条**（2026-11-04..11-13）。这些行的旧 `label` 全是「涉诈」，agent 判定：违规 3,487、正常 406、涉诈 73。probe 阳性率：

| agent 判定 | n | argmax | devR95 | FPR5 | FPR10 |
|---|---:|---:|---:|---:|---:|
| 违规（4.1 硬负例候选） | 3,487 | 0.5% | 0.5% | **0.8%** | 2.5% |
| 正常 | 406 | 2.2% | 3.0% | 3.9% | 8.6% |
| 涉诈（待复核） | 73 | 21.9% | 21.9% | 23.3% | 35.6% |

- 在 3,893 条 agent 判违规/正常的非涉诈行上，FPR5 的阳性率只有 0.8%（违规）和 3.9%（正常），按日稳定（违规组 0–2.2%）。这批硬 4.1 负例没有出现 gate 上那种 20%+ 的误报。
- agent 涉诈 73 条中：ab贷 14 条 probe 平均 P=0.746、12/14 ≥0.5（强一致，最可能是真 4.2）；引导加微 40 条平均 0.077、2/40 ≥0.5；手机租赁 9 条平均 0.043、0/9（agent 可能误报，或 probe 无该类训练样本）。
- 因此时间外推的**负类成本**已经可以评估（FPR5 约 1%）；**召回**仍要等 207 条复核，且正例可能只有几十条，CI 会很宽。
