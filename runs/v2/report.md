# v2（4.2 涉诈）· 线性 probe 复评

- 模型：`Qwen/Qwen3.5-4B`，4 层隐藏状态（8/16/24/32），最后一 token。
- 数据：`eval_v2/goldens.jsonl`（9381 条）；cal/dev/gate = 3755/1876/3750。
- 主门禁：`split=gate` 且 `cohort=human_0729`（578 条）；另有 `human_cq_normal` gate 632 条用于正常类 recall。
- 协议：层/L2/类权重只在 cal 上拟合、dev 上选择；gate 只在冻结后评分一次。v2 任务与 rubric 见 `eval/task_v2.py`。

## 1. 结论

- 主门禁（argmax）：balanced accuracy **0.891**，涉诈 recall **0.934**，非涉诈 recall **0.848**，ECE **0.024**。
- 绝对门禁（前 4 项）：**未通过**；含「相对 v1 probe」参考条件的完整门禁：**未通过**。
  - ✅ balanced accuracy ≥ 0.70：0.891
  - ❌ 涉诈 recall ≥ 0.95：0.934
  - ✅ 非涉诈 recall ≥ 0.50：0.848
  - ✅ ECE ≤ 0.10：0.024
  - ✅ 相对 v1 probe（诊断基线）的 bal 提升 ≥ +5pp：+0.290 [0.251, 0.327]
  - ✅ 配对 bootstrap CI 下界 > 0：[0.251, 0.327]

**操作点敏感性（阈值均在 dev 上冻结，未看 gate）**：

| config | threshold | bal | 涉诈 R | 非涉诈 R | ECE | 四项绝对门禁 |
|---|---|---|---|---|---|---|
| probe@dev-R95 | 0.3900 | 0.877 | 0.945 | 0.809 | 0.022 | 未通过 |
| probe@FPR5% | 0.3075 | 0.856 | 0.951 | 0.761 | 0.029 | 通过 |
| probe@FPR10% | 0.1403 | 0.804 | 0.983 | 0.626 | 0.057 | 通过 |

> argmax（0.5）是主决策。`probe@dev-R95` 的阈值由 dev 上「涉诈 recall ≥ 0.95 前提下最大化非涉诈 recall」冻结；`@FPR5`/`@FPR10` 由 dev 正常类经验 FPR 冻结。三者都是 gate 之前可复算的 dev-only 操作点，但事后在 gate 上比较它们仍引入选择偏差；采用哪个点取决于误报成本，不能用 gate 结果反向选点。

- 过 recall 门禁的 dev 冻结点在主门禁上的实际误报：probe@FPR5% 23.9%、probe@FPR10% 37.4%；argmax 误报最低（15.2%）但 recall 未达标。

- 对比参考：冻结 v1 probe 在同一批 578 条 gate 行上按 v2 标签重评分，balanced accuracy **0.601**，涉诈 recall **0.902**，非涉诈 recall **0.300**。

## 6. 限制

- 主门禁的 normal 类只有 human_0729 gate 的 230 条 + human_cq_normal 的 632 条；前者用于门禁，后者只作补充正常 recall，不能替代时间外推。
- `agent_1022` 的 6,353 条是 10.22 人批复核，107 条保留 spec 裁定；两套口径在 107 条上仍有分歧（见 conflicts CSV）。
- 本报告是 transcript-only 结论；没有使用业务归属/资质等通话外字段。
